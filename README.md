## FAQ
**Q: I bought supporter badges but they don’t show up.**  
A: Please try restarting the app. If the issue persists, contact support with your Apple ID purchase receipt.  

**Q: Does Coffeemeter collect personal data?**  
A: No personal data is collected. See the [Privacy Policy](https://silentlatex.github.io/coffeemeter-support/privacy.html) for details.
